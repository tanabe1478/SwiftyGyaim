# BUG-037: クリップボードの内容がログに生で残っていた

- **日付**: 2026-09-12
- **症状**: `gyaim.log` に `Clipboard updated: "..."` としてクリップボード先頭50文字が記録され、改行を含む内容で行が壊れていた（1.5日で68行、うち21行が継続行）。コミットメッセージやパスがそのまま入る。
- **原因**: `CopyText.set` が診断のため内容を出力していた。
- **修正**: 文字数のみ記録する。
- **教訓**: ユーザー入力由来の文字列は長さやハッシュだけをログに出す。候補や入力パターンのログも同じ観点で見直し対象。
