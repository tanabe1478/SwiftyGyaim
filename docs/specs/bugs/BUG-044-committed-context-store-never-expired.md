# BUG-044: 引き継ぎ文脈の保管庫が失効した本文を捨てずに追記していた

- **Issue**: なし
- **発見日**: 2026-11-03
- **影響**: `CommittedContextStore` は 300 秒を過ぎた本文を引き継がないが、本文そのものは消さずに次の確定を追記していた。17:27 の文に 18:02 の「ごめん再開して」が足され、18:04 のコントローラが 80 文字まとめて引き継いだ。10/01〜11/03 の引き継ぎあり確定 6,319 件のうち 1,927 件で、モデルに渡った 20 文字の中に 300 秒以上の空きがあった。
- **原因**: `record(text:bundle:now:)` が既存エントリの鮮度を見ずに連結していた。失効の判定は `inheritableContext` だけにあった。
- **修正**: `record` に `carryOverSeconds` を渡し、既存エントリが窓の外なら捨ててから追記する。窓 0（引き継ぎ無効）では最新の確定だけが残る。
- **検証**: `CommittedContextStoreTests.testStaleTextIsDroppedBeforeAppending`。順位への効果は ADR-040 の評価で「300 秒の空きで切る」に相当し、中立（4 / 12）。意図との食い違いを直すのが目的で、変換の改善は期待しない。
- **教訓**: 失効の判定を読む側だけに置くと、書く側の蓄積が判定をすり抜ける。
- **関連ADR / PR**: ADR-035、ADR-040
