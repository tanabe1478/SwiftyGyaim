# BUG-049: 名詞「気持ち」が「気持ちい」の存在で未完成語幹として沈む

- **Issue**: なし（dogfood の報告「kimoti で 気持 が 気持ち より先に来る」）
- **発見日**: 2026-11-12
- **影響**: `kimoti` で、学習頻度が高い「気持ち」（8 回）より「気持」（6 回）が先頭に出る。何度選び直しても変わらない。2026-11-10 のログでも同じ（気持ち 4 回、気持 3 回）。同じ形で「なら」（ならい）、「が」（がい）、「しま」（しまい）、「かっこ」（かっこい）、「お手伝」（お手伝い）なども減点されていた。
- **原因**: `incompleteStemPenalty`（-4.0）は「1 文字足して い で終わる候補が同じ一覧にあるか」という文字の並びだけで書きかけを推定する。候補一覧には形容詞「気持ちいい」の語幹「気持ちい」（`dict.txt` の 39→40）があり、名詞「気持ち」（3→4）がその書きかけと判定された。モデルの採点（-0.009 対 -0.122）と学習（+5.61 対 +6.34）では 気持ち が上だが、減点で逆転する。BUG-025・BUG-043 と同じ規則の 3 回目の誤判定で、過去 2 回は文字の例外（い / た / だ で終わる語）を足して塞いでいた。
- **修正**: 書きかけかどうかを辞書に聞く。`grammar-dict.txt` の `# @stem-classes` 行で活用語幹の接続クラス（五段語幹・未然形・形容詞語幹・ない / たい の な / た）を宣言し、`ConnectionDict.completeWords(among:)` が、文字規則に当たった候補について「その読みで、語幹クラス以外で終わる導出があるか」を調べる。あれば `AIRerankCandidate.completeWord = true` になり、い の規則の対象外になる。っ で終わる語の規則と、い / た / だ の例外は変えていない（辞書に導出のない学習語のため）。判定は `AIReranker.isIncompleteStem` に一本化し、減点と同音異義語レビューの除外（`isIncompleteStemCandidate`）が同じものを使う。取り込み辞書はクラス番号が違い `# @stem-classes` を持たないので、従来の文字規則のままになる。
- **検証**: 同梱辞書の読み 6,279 件とタイピングコーパスの打鍵途中 1,312 件を実際の検索に流し、候補上位 40 件で現行規則が減点する語を数えた。47 語のうち、完結した語 13 語（気持ち、かっこ、からか、が、きれ、しな、しま、すくな、だらし、なさ、なら、正し、お手伝）が対象外になり、語幹 34 語（くださ、下さ、いらっしゃ、向か、味わ、つまらな、済まな、付き合 など）は減点されたまま。`IncompleteStemClassTests`（4 件）がこの表の代表例、実ログの数値での並び順、取り込み辞書での挙動、語幹クラスに語頭の行が後続しないことを固定する。判定の 1 行を外すと表と並び順のテストが失敗する。タイピングシミュレーションは変更前後で同値（本 0.904 / 0.892、保留 0.893 / 0.904）。
- **教訓**: 「候補集合内の別候補を根拠に減点する」規則は、文字の例外を足しても同じ形で再発する。品詞は辞書が持っているので、文字から推定せず辞書に聞く。なお `sukuna` の時点では「少ない」が候補に出ないため（先読みは最後の 1 エントリだけ）、この規則が実際に働くのは W+い が辞書の 1 行になっている語に限られる。
- **関連ADR / PR**: BUG-025、BUG-043、ADR-042（`grammar-dict.txt`）
