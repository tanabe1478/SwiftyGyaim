# SwiftyGyaim 利用ガイド

macOS 用の日本語入力プログラム SwiftyGyaim を使う人向けの説明です。開発者向けの情報（ビルド、設計、仕様）は README と `docs/specs/` にあります。

対象バージョン: 1.10（2026-11-06）

## 1. 導入

### インストール

1. [最新リリース](https://github.com/tanabe1478/SwiftyGyaim/releases/latest) から `SwiftyGyaim-<version>.pkg` をダウンロードする
2. pkg を開き、画面の指示に従う。途中で管理者パスワードを求められる
3. 「システム設定」>「キーボード」>「入力ソース」の「編集…」を開き、左下の「+」から「日本語」>「Gyaim」を追加する（初回だけ）
4. メニューバーの入力メニューで Gyaim に切り替える

pkg を開いたときに「開発元を検証できないため開けません」と出たら、pkg を Control キーを押しながらクリックして「開く」を選ぶか、「システム設定」>「プライバシーとセキュリティ」の下部にある「このまま開く」を押してください。配布ビルドは Apple の公証を受けていないためです。

インストール先は `/Library/Input Methods/SwiftyGyaim.app` です。

### アップデート

新しい pkg を開いて上書きインストールするだけです。インストーラが古いプロセスを終了し、次に日本語入力を使ったときに新しい版が動きます。入力ソースの再追加は不要です。

### アンインストール

1. 「システム設定」>「キーボード」>「入力ソース」から Gyaim を削除する
2. `/Library/Input Methods/SwiftyGyaim.app` を削除する（管理者権限が必要）
3. 学習した内容や設定も消したい場合は `~/.gyaim/` フォルダを削除する

## 2. 基本の入力

ローマ字を打つと、打っている途中から候補が出ます。読みを全部打ち終える前に目的の語が出ていれば、そのまま選べます。

| 操作 | キー |
|---|---|
| 次の候補へ | Space |
| 前の候補へ | Backspace または Esc（候補を送っている途中のとき） |
| 1 文字消す | Backspace または Esc（先頭候補にいるとき） |
| 候補を選んで確定 | Enter、または候補ウィンドウの番号 1〜9 |
| 打った文字をそのまま確定 | Enter（先頭候補がローマ字のままのとき。下記） |
| ひらがなで確定 | `;`、F6、Ctrl+Shift+U |
| カタカナで確定 | `q`、F7、Ctrl+Shift+I |
| Google 変換 | Tab、または読みの末尾に `` ` `` を付ける |
| 候補を辞書から消す | Shift+X（候補を選んでいるとき） |

候補ウィンドウの一番上は、打っているローマ字そのものです。Space を押すと 2 番目以降の候補に進みます。これは、短い読みを打った直後に Enter を押しても長い候補が勝手に入らないようにするための仕組みです。

先頭候補（ローマ字のまま）で Enter を押すと、読みがちょうど一致する語だけを集めた候補に切り替わります。ひらがな、カタカナ、辞書の語が並ぶので、そこから Space や番号で選んで Enter で確定します。

Shift+Tab は何もしません。大文字を含む入力はそのまま通します。

### 候補ウィンドウの見た目

2 種類あり、設定画面の「表示スタイル」で切り替えます。

- クラシック表示（既定）: 元の Gyaim と同じ吹き出し。候補を横に並べ、1 画面に 11 個まで
- リスト表示: 縦に並べ、番号付きで 9 個まで

どちらも、続きがあるときは末尾に ▼ が出ます。Space で先に進むと表示がスクロールします。

## 3. 辞書と学習

候補は 3 つの辞書から集めます。

| 辞書 | 中身 | 置き場所 |
|---|---|---|
| 接続辞書 | 同梱の固定辞書。活用や複合語を組み立てる | アプリの中（差し替え可能、下記） |
| ユーザー辞書 | 自分で登録した語。最優先で出る | `~/.gyaim/localdict.txt` |
| 学習辞書 | 確定した語を覚える。使うほど上に来る | `~/.gyaim/studydict.txt` |

加えて、確定する直前の文を一緒に覚える「文脈学習」があります（`~/.gyaim/contextdict.txt`）。同じ文脈では、前に選んだ同音異義語が上に来ます。

### 語を登録する

- 文字列を選択するか、コピーした直後（5 秒以内）に読みを打つと、その文字列が候補の 2 番目に出ます。選んで確定すると、その読みでユーザー辞書に登録されます（改行を含むものと 30 文字を超えるものは登録せず、挿入だけします）
- 入力メニューの「ユーザー辞書...」で一覧を開き、「追加」「削除」「保存」で直接編集できます。列は「読み」と「単語」で、読みはローマ字でもひらがなでも構いません

### 覚え間違いを直す

- 変換中に候補を選んで Shift+X を押すと、その語を学習辞書とユーザー辞書から消します
- 同じ読みを 15 秒以内に別の語で打ち直すと、直前の確定の学習を自動で取り消します。誤変換を Enter で確定してしまい、すぐ消して打ち直したときに、誤った語が学習に残らないためです
- 設定画面の「疑わしい学習エントリを確認...」で、打ち間違いの形で覚えた語や長く使っていない語を一覧し、選んで消せます
- 学習辞書の上限は 10,000 語です。設定画面の「淘汰方式」で、古いものから消す（MRU）、消さない（淘汰なし）、使用頻度と時間で評価して消す（スコアベース）を選べます

## 4. 候補の並び順

辞書から集めた候補は、同梱の小さな言語モデルが直前の文脈と読みから採点し、学習辞書の頻度や文脈学習の記録と合わせて並べ替えます。採点は打鍵の裏で動き、結果が届くと候補ウィンドウが並び替わります。連続して打っている間は見えず、手が止まると反映されます。

設定画面の「候補の並べ替え」で切れます。

- 「通常入力で候補を並べ替える」を OFF にすると、辞書の順のまま出ます
- 「並べ替えに同梱モデルを使う」を OFF にすると、モデルを使わず、読みの完全一致を優先する簡単な規則だけで並べます
- 「同梱モデルを読み込む」を OFF にすると、モデル自体を読み込みません

## 5. Google 変換

辞書にない語（人名、地名、新しい語）は Google の変換サービスに問い合わせられます。変換中に Tab を押すか、読みの末尾にトリガー文字（既定 `` ` ``）を付けます。例: `meguro`` ` `` で 目黒。

- 読みがインターネット経由で Google に送られます。送りたくない場面では使わないでください。通常の入力では送信しません
- 応答がない場合は 3 秒で諦め、元の候補のままになります
- トリガー文字と起動ショートカットは設定画面の「キー操作」で変えられます

## 6. 設定画面

入力メニュー（メニューバーの Gyaim アイコン）の「Gyaim 設定...」で開きます。すべての項目は変更するとすぐ保存され、保存ボタンはありません。「初期値に戻す」で画面にある設定とキー割り当てをまとめて既定値に戻します。

| セクション | 項目 |
|---|---|
| キー操作 | ひらがな確定・カタカナ確定・候補削除の単独キー（1 文字。空欄で無効）と、修飾キー付きショートカットの一覧。Google 変換のトリガー文字とショートカット |
| 候補 | 表示スタイル（リスト / クラシック）、クリップボードの内容を候補に出す、選択テキストを候補に出す |
| 学習辞書 | 淘汰方式、平仮名の確定を学習する、完全一致の読みを優先する、疑わしい学習エントリの確認、ユーザー辞書の編集 |
| 候補の並べ替え | 並べ替えの ON/OFF、同梱モデルの使用、文脈学習の ON/OFF とクリア |
| 接続辞書 | 元の Gyaim の辞書（masui/Gictionary）を URL から取り込む。「内蔵辞書に戻す」で元に戻す |
| ログ | 動作ログの ON/OFF、ログの削除、Finder で表示 |

ショートカットの追加は「+ 追加」で行を増やし、「記録」を押してから目的のキーを押します。行の「×」で消します。ひらがな確定とカタカナ確定は最低 1 つの行を残します。

単独キーの欄に 2 文字以上や記号以外のトリガー文字を入れると、音が鳴って元の値に戻ります。

ターミナル系のアプリ（Terminal、iTerm2、Ghostty など）は Ctrl+キーをアプリ側で先に処理するため、Ctrl 付きのショートカットが届かないことがあります。その場合は単独キー（`;` と `q`）を使ってください。

設定は `~/.gyaim/settings.json` に保存されます。画面にない細かい項目（モデルの重みなど）もこのファイルで変えられますが、通常は触る必要はありません。

## 7. 困ったとき

### 候補が出ない、日本語にならない

- 入力メニューで Gyaim が選ばれているか確認する
- パスワード入力欄にいる間は、macOS の仕組みで日本語入力が使えない。入力欄を離れると戻る
- まれに、パスワード欄を使ったアプリが終了したあとも macOS 側の「セキュア入力」状態が残り、Gyaim が入力メニューで灰色になることがある。その状態になったら、直前にパスワードを入れたアプリを Cmd+Q で終了する。それでも戻らなければ Ctrl+Cmd+Q で画面をロックして解除する

### 候補ウィンドウが変な場所に出る

ブラウザ上のエディタ（Google Docs など）は、カーソルの位置を正しく教えてくれないことがあります。Gyaim は直前の正しい位置やマウスの位置で補いますが、ずれることはあります。

### 直前に打った文字が消せない

ローマ字 1〜2 文字だけの状態（かなに変換できない途中）でひらがな確定キーを押すと、下線付きの文字が残って Backspace で消せないことがあります。次の文字を打てば上書きされて直ります。既知の不具合で、修正を予定しています。

### 設定で表示スタイルを切り替えたら候補が空になった

バージョン 1.9 以前の不具合です。1.10 で直りました。1.9 以前では、アプリを切り替えると直ります。

### 学習をやり直したい

- 学習辞書だけ: `~/.gyaim/studydict.txt` を削除するか空にする（Gyaim を終了している間に）
- 文脈学習だけ: 設定画面の「文脈学習をクリア」
- 設定だけ: 設定画面の「初期値に戻す」

### 不具合を報告したい

設定画面の「ログ」でロギングを ON にすると `~/.gyaim/gyaim.log` に動作が記録されます。ログには打った読みと確定した語が含まれるので、共有するときは内容を確認してください。報告は [GitHub の Issues](https://github.com/tanabe1478/SwiftyGyaim/issues) へ。

## 8. データとプライバシー

- 学習辞書、ユーザー辞書、文脈学習、設定、ログはすべて `~/.gyaim/` の中にあり、外部には送られません
- 外部に送るのは Google 変換を使ったときの読みだけです
- 同梱の言語モデルは公開データだけで学習したもので、あなたの入力はモデルの学習に使われません。候補の採点はこの Mac の中で行います
