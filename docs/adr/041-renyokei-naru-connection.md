# ADR-041: 連用形から「なる」への接続を接続辞書に足す

## Status

Superseded by ADR-042（行の置き場所を `grammar-dict.txt` に移した。接続クラス 224 の設計は ADR-042 に引き継ぐ）

## Decision

同梱の接続辞書 `Resources/dict.txt` に接続クラス 224（連用形の後ろに なる を受ける）を導入し、4 行を追加する。

```text
ku	*く	40	224      # 形容詞の連用形（眠く・辛く・高く）
ni	*に	19	224      # 形容動詞の連用形（静かに・好きに）
ku	*く	54	224      # 否定 ない の連用形（できなく・見えなく）
na	*な*	224	16      # なる の語幹。活用はら行五段（クラス 16）の既存行
```

なる の活用形（なる / ならない / ならず / なった / なります / なれば / なって / なりそう …）は `na な 15 16` と同じクラス 16 の語尾行をそのまま使うので、活用形ごとの行は書かない。表記はひらがなの なる だけで、成る / 鳴る は出さない。

## Context

形容詞語幹（39 → 40）から `*く` までは組み上がるが、その出力 77 は句読点しか受けず、形容動詞の `*に`（19）は終端だった。動詞語幹クラス 15 に入る出力を持つ行が 1 つもないため、「眠くなる」「静かになる」はどうつないでも合成されず、学習辞書には はやくなった / できなくなる / になる？ のようなひらがな確定が 49 件たまっていた。

## Consideration

- なる の活用形を `*くなる` `*くならない` … として個別に書く: 行数が増え、クラス 16 にある活用形（りそう / ったら / っても …）を取りこぼす。
- 中間クラスを 1 つ足して既存の五段活用へつなぐ（採用）: 3 つの連用形から同じクラスに出し、語幹行 1 本で全活用形が得られる。
- 名詞 + になる（医者になる）も同時に扱う: 名詞（3 → 4）の後ろに助詞を受ける行自体がなく、別の設計になるので対象外。

## Consequences

- `nemukunaru` → 眠くなる、`nemukunaranai` → 眠くならない、`nemukunarazu` → 眠くならず、`sizukaninaru` → 静かになる、`dekinakunaru` → できなくなる が接続辞書から出る。`DictionarySearchGoldenTests` の 268 クエリの相対順は不変。
- 前方一致では な の次の 1 文字（`nemukunar` / `nemukunat`）まで打った時点で候補が出る。`nemukuna` では出ない（前方一致は最後の 1 エントリしか先読みしない）。
- Gictionary から取り込み直すとこの 4 行も消える。サ変の行（ADR-030）と同じく足し直す。
