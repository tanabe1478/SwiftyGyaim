# ADR-034: Mozc の公開辞書を接続辞書の語彙として同梱する

## Status

Accepted (2026-09-26)

## Decision

Mozc（Google 日本語入力のオープンソース版）の辞書 `src/data/dictionary_oss/dictionary0*.txt` から名詞類を取り出し、Gictionary の接続クラスを付けた `Resources/mozc-dict.txt`（かなキー、約 28 万語 / 33 万行 / 12 MB）を生成して同梱する。`ConnectionDict` は同梱の `dict.txt`（または取り込んだ `~/.gyaim/connectiondict.txt`）に続けてこのファイルを読み、1 つの辞書として扱う。同じ (かな, 表記, クラス) の行は先のファイルが勝つ。

生成は `Tools/dict/build-mozc-connection-dict.py`。Mozc の右接続 ID（後ろに何が続けるか）で分類する。

| Mozc の品詞（右 ID） | 接続クラス |
|---|---|
| 名詞,サ変接続（再起動・実装・レビュー） | `3 4` と `50 51`（する の活用形へ） |
| 名詞,形容動詞語幹（簡単） | `3 4` と `18 19`（な / に へ） |
| その他の名詞（一般・接尾・固有名詞・数・副詞可能） | `3 4` |
| 副詞（のみ） | `24 0` |

左 ID が 名詞 / 接頭詞（再+起動 のような複合語）/ 副詞 / 感動詞 の行だけを対象にし、動詞・形容詞は Gictionary の活用行に任せる。コスト（Mozc の −log 確率。小さいほど頻出）が 7,500 以下、地名・人名は 6,000 以下に絞る。読みが表記と同じひらがなの行は除く（かな確定で出せる）。行はコスト順に並べ、辞書順がそのまま頻度順になる。

## Context

タイピングシミュレータ（ADR-032 時点）で、自然な区切りの候補なし 30 件の大半が名詞+名詞の複合語（要件定義・開発環境・設定画面）と、サ変クラスを持たない語だった。Gictionary 由来の同梱辞書は約 1.9 万語で、Mozc の公開辞書はその 93% を含む約 98 万表記を持ち、これらの複合語も 1 語として収録している（要件定義 6048、設定画面 5564、再起動 1378）。

ADR-033 のかなキー索引により、Mozc のかな読みをローマ字に展開せず 1 語 1 行で持てる。

## Consideration

- 名詞+名詞の合成規則を接続辞書に足す: 用件定義 のような組み合わせが際限なく出る。Mozc は複合語を 1 語として持つので不要。
- 全品詞を取り込む: 動詞・形容詞は活用形ごとの行になり、Gictionary の語幹+語尾の分解と二重になる。今回は名詞類に限る。
- コスト閾値を上げる（7,800 で 53 万語）: 念の為（7,662）などが入るが、ファイルと読み込み時間が 1.2 倍になる。辞書にない語はモデル生成（ADR-035 予定）で補う方針にし、7,500 に留める。
- 別ファイルにする（採用）: `dict.txt` は MIT（Gictionary）、Mozc は BSD-3 + IPAdic の表示が要る。ライセンスごとにファイルを分け、`Resources/DICTIONARY_THIRD_PARTY_NOTICES.txt` に表示を同梱する。

## Consequences

- シミュレータ（64 文、学習なし）: 自然な区切りの 1 位率 0.811 → 0.876、候補なし 27 → 13 件、操作回数 664 → 654。普段の区切りは 0.893 → 0.904。
- 残った候補なしは、動詞（見積もる・書き直す）、形容詞+名詞（良いところ）、敬語の定型（お願いいたします）、Mozc にない複合語（ユーザー設定・設定ファイル）。
- 読み込みが 1 プロセスあたり 0.15 秒 → 0.8 秒になる（33 万行の解析と索引構築、Release。バイト単位の行分割と 1 回のかな整列にして 1.3 秒から短縮）。接続辞書はプロセス内で共有され、`AppDelegate` が起動時にバックグラウンドで先読みするので、最初のコントローラは通常待たない。
- 1 打鍵の接続辞書検索は 2,000 件の打ち切りで平均 1.9 ms、最大 4.6 ms（Release）。
- 略した読み（`kannsu` → 関数）は Gictionary 行のまま残り、Mozc の正しい読み（かんすう）と共存する。Mozc 由来の同音の語（かんす: 関す・カンす）が並ぶ場合がある。
- 前方一致の候補では Gictionary 行が先に来るため、Mozc 由来の予測候補が heuristic の対象（辞書順の上位 24 件）に入るのは、Gictionary の予測候補が少ない読みに限られる。読みを打ち切った完全一致では問題にならない。
- アプリの配布サイズが約 12 MB（圧縮前）増える。
- `Tools/dict/suggest-connection-entries.py` は `dict.txt` だけを見るため、Mozc に既にある語も提案し得る。
